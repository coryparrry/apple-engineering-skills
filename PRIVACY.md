# Privacy

Apple Engineering Skills is a collection of local instruction files. The plugin does not bundle a network service, account system, analytics client, or data store, and it does not itself collect or transmit personal information.

Skills may guide an agent to inspect source code, build artifacts, logs, diagnostics, screenshots, accessibility data, model prompts, or telemetry while completing a user-authorized task. Those workflows require data minimization, explicit authorization boundaries, and privacy-safe diagnostics. The repository does not grant an agent permission to upload or disclose such data.

The tools and model host used to run a skill may have their own privacy practices. Review those services separately before using them with sensitive material.

Questions or reports may be opened through the repository's GitHub issue tracker.
